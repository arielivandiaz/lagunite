Key differences: (1) Only 2 breakpoints: x mobile ≤639px, d desktop ≥640px. (2) .row/.col already include display:flex. (3) Spacing uses semantic names: xs s (base) l xl. (4) Many .bg-* also set text color. (5) Use component classes (.card, .btn, .alert) instead of utility stacks.
