# Lagunite Library Index

This document serves as a map of all components, utilities, and configurations within the Lagunite library. Each item has a unique ID for easy searching and referencing.

---

## 🏛️ `000` - System Core

The fundamental core upon which the entire library is built.

* **`#000` - Color Palette:** Contains all available raw color options.
    * *Location:* `src/css/00-core/01-palette.css`
* **`#001` - Semantic Theme:** Assigns a purpose to the palette colors (primary, secondary, etc.).
    * *Location:* `src/css/00-core/_01-theme.css`
* **`#002` - Typography:** Defines font families, sizes, and weights.
    * *Location:* `src/css/00-core/_02-typography.css`
* **`#003` - Measures & Scales:** Defines the system for spacing, radii, borders, and shadows.
    * *Location:* `src/css/00-core/_03-measures.css`
* **`#004` - Media Queries:** Contains the aliases for responsive breakpoints.
    * *Location:* `src/css/00-core/_04-media.css`
* **`#005` - Root Styles & Reset:** Applies base styles to `<html>`, `<body>` and resets browser styles.
    * *Location:* `src/css/00-core/_root.css`
