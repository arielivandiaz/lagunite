Flex en Lagunite

Guía de aprendizaje: "Si quiero este layout, uso estas clases."

Cómo leer esta guía: cada tarjeta muestra un patrón concreto con su descripción de uso, las clases involucradas como badges, y un ejemplo visual con items coloreados. Redimensiona la ventana para ver los efectos responsive.

7 · Order — reordenar items visualmente sin tocar el HTML

El HTML dice A·B·C·D pero la pantalla muestra D·A·C·B
.order-first .order-last .order-2

Útil para reordenar layouts en responsive sin duplicar markup. Prefijos xorder-* y dorder-* aplican por breakpoint.
