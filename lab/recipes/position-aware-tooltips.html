Position-aware tooltips

Default: CSS-only [data-tooltip]. Progressive: Popover + anchor positioning (.tooltip-anchor / .tooltip-popover) when supported.

Hover the buttons. Near viewport edges, anchored popovers can flip via position-try-fallbacks. Arrow flip via @container anchored() is still a GAP.
CSS-only (always)
Popover + anchor (progressive)
Anchored tip — flips if there is no room above.

Without anchor support, the popover still opens (UA default placement).

Hero classes

  • [data-tooltip] · .tooltip-bottom / left / right
  • .tooltip-anchor · .tooltip-popover (+ Popover API)
