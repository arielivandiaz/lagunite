Resilient action panel

Default: .dropdown + .open. Progressive: Popover + .dropdown-trigger / .dropdown-panel with position-try-fallbacks (flip near edges).

This is a button group in a popover, not a full ARIA menu. Do not add role="menu" / aria-haspopup unless you implement arrow-key navigation.
Classic (.open)
Popover + anchor (progressive)

Place the trigger near a viewport corner to see flip. Without anchor support, the popover still opens (UA default placement).

  • .dropdown-trigger · .dropdown-panel (+ Popover API)
