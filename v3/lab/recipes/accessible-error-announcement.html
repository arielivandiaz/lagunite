Accessible error announcement

Visual :user-invalid and programmatic aria-invalid stay in sync — AT only hears “invalid” after the user has interacted, not on first focus of an empty required field.

Use a screen reader or inspect aria-invalid in DevTools after blur / while fixing the field.

Bridge pattern

On blur/focus (capture): set aria-invalid from el.matches(':user-invalid'). On input: clear when fixed. Never set aria-invalid="true" on page load for empty required fields.
