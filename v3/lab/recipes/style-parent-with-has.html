Style parent with :has()

When a field becomes :user-invalid, ancestors can react in CSS — label color via .form-group:has(...), surface via .form-surface:has(:user-invalid).

Leave username empty and blur or submit — the card edge and label turn error without JS class toggles.

Hero classes

  • .form-group:has(:user-invalid) .form-label (built-in)
  • .form-surface:has(:user-invalid) — opt-in ancestor chrome
  • Scope :has() to a section/card — never body:has(...)
  • App-owned: still use .has-error when JS owns validity
