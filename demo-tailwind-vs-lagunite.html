Tailwind vs Lagunite

Side-by-side code comparison. Both produce the same visual result — the difference is the syntax.

<div class="row gap-4"> <!-- .row already sets: display:flex; flex-wrap:wrap; justify-content:center; align-items:center --> <div>A</div> <div>B</div> <div>C</div> </div>

6. Responsive Patterns

Tailwind: prefix before class. Lagunite: prefix merged into class name.

Tailwind
Lagunite
<!-- Stack on mobile, row on desktop --> <div class="flex flex-col sm:flex-row gap-4"> <div class="w-full sm:w-1/3">Sidebar</div> <div class="w-full sm:flex-1">Main</div> </div> <!-- Hide on mobile, show on desktop --> <div class="hidden sm:block"> Desktop only </div> <!-- 1 col mobile → 3 cols desktop --> <div class="grid grid-cols-1 sm:grid-cols-3 gap-4"> ... </div>
<!-- Stack on mobile, row on desktop --> <div class="col drow gap-4"> <!-- col = default, drow = desktop row --> <div class="wp100 dwp-1\/3">Sidebar</div> <div class="flex-1">Main</div> </div> <!-- Hide on mobile, show on desktop --> <div class="d-none dd-block"> Desktop only </div> <!-- 1 col mobile → 3 cols desktop --> <div class="grid xgrid-cols-1 dgrid-cols-3 gap-4"> ... </div>
