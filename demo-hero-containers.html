Semantic containers

Cada tipo tiene un max-width pensado para su contexto. Todos centrados automáticamente.

.container-prose (65ch)

Este texto está dentro de un container-prose, limitado a 65 caracteres por línea — el ancho ideal para lectura cómoda. Perfecto para artículos, blog posts, documentación y cualquier contenido de texto largo que necesite buena legibilidad.
